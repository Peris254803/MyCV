📱 MY CV – My Personal Profile

👋 About the Project

My CV is a personal profile Android application developed to showcase my personal details, education background, technical skills, achievements, experience, and hobbies in a simple and organized format.

The application presents my CV digitally, making it easy for people to learn more about my background and abilities.

🚀 How to Run the Project

1. Install Android Studio on your computer.
2. Download or clone this repository.
3. Open Android Studio.
4. Select Open and choose the project folder.
5. Allow Gradle to sync and download the required dependencies.
6. Connect an Android phone with USB debugging enabled or start an Android emulator.
7. Click the Run ▶ button to launch the application.
